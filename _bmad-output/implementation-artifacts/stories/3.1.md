# Story 3.1 查找宠物用品

实施状态：`done`。状态与`sprint-status.yaml`一致，技术验证和人工接受分别记录。

## 用户故事

作为商城访客，我希望按用途找到需要的宠物用品，以便找到符合用途的可售用品。

## 关联与前置

- 功能需求：FR-13。
- 页面入口：`/shop、/shop/:id`。
- 前置故事或条件：运行环境及商品演示数据。
- 详细业务规则：[PRD](../../planning-artifacts/PRD.md)；技术约束：[架构](../../planning-artifacts/architecture.md)。

## 输入与主流程

消费者按分类和关键词浏览公开商品，查看图片、描述、金额及库存。目录仅返回允许公开的商品，推荐项按约定优先展示。

## 验收标准

### AC-3.1-01

只展示上架商品，名称分类组合条件取交集，推荐商品优先。

### AC-3.1-02

商品详情包含主图、说明、分类、价格和当前可售库存。

### AC-3.1-03

下架旧链接不可购买，库存0显示缺货且不能加购。

### AC-3.1-04

无结果、请求失败与加载中分别显示；查询失败不能用假商品替代。
