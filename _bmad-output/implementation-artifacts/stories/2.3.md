# Story 2.3 申请并查看本人进度

实施状态：`done`。状态与`sprint-status.yaml`一致，技术验证和人工接受分别记录。

## 用户故事

作为领养申请人，我希望提交申请并跟踪与本人有关的进度，以便主动表达领养意愿并跟踪处理进度。

## 关联与前置

- 功能需求：FR-09 FR-10。
- 页面入口：`/pets/:id、/adoptions`。
- 前置故事或条件：1.1、2.1、2.2。
- 详细业务规则：[PRD](../../planning-artifacts/PRD.md)；技术约束：[架构](../../planning-artifacts/architecture.md)。

## 输入与主流程

申请人主动向他人待领养宠物提交申请，并在本人进度中查看结果。服务端在宠物事务内检查自申请、重复有效申请及资源状态。

## 验收标准

### AC-2.3-01

两名不同非发布者可分别申请同一待领养宠物，各生成一份PENDING记录。

### AC-2.3-02

同一申请人并发及重复提交最多有一份有效申请，重试返回已有记录。

### AC-2.3-03

游客、本人发布者，以及面对非待领养宠物的新申请均被拒绝。

### AC-2.3-04

申请人只看本人记录；发布者只看本人宠物收到的申请，不能读取无关申请数据。
