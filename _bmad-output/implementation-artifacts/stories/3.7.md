# Story 3.7 查询物流并确认收货

实施状态：`done`。状态与`sprint-status.yaml`一致，技术验证和人工接受分别记录。

## 用户故事

作为商品收件人，我希望查看物流并完成收货确认，以便查看配送信息并确认订单完成。

## 关联与前置

- 功能需求：FR-21。
- 页面入口：`/orders`。
- 前置故事或条件：3.5、4.2。
- 详细业务规则：[PRD](../../planning-artifacts/PRD.md)；技术约束：[架构](../../planning-artifacts/architecture.md)。

## 输入与主流程

消费者在本人已发货订单查看承运方和物流单号，确认实际收货后完成订单。越权和不符合状态的收货请求被拒绝。

## 验收标准

### AC-3.7-01

发货后本人可查看承运方和物流单号，内容来自管理员已保存信息。

### AC-3.7-02

本人SHIPPED确认收货转COMPLETED，重复确认保持完成。

### AC-3.7-03

PENDING、PAID或CANCELLED不得直接收货，其他用户不得代确认。

### AC-3.7-04

收货不再次扣库存，不修改订单金额或历史商品快照。
