# 后端单模块目录

后端现在是一个 Maven / Spring Boot 工程，只有 backend/pom.xml，所有源码集中在 backend/src 下。

```text
backend/
├─ pom.xml
└─ src/
   ├─ main/
   │  ├─ java/com/petcommunity/
   │  │  ├─ PetCommunityApplication.java
   │  │  ├─ controller/
   │  │  ├─ service/
   │  │  ├─ mapper/
   │  │  ├─ entity/
   │  │  ├─ dto/
   │  │  ├─ vo/
   │  │  ├─ utils/
   │  │  ├─ validation/
   │  │  ├─ common/
   │  │  ├─ config/
   │  │  ├─ security/
   │  │  ├─ handler/
   │  │  └─ task/
   │  └─ resources/
   │     ├─ application.yml
   │     └─ mapper/
   └─ test/java/com/petcommunity/
      └─ AccountBoundaryTest.java
```

entity、dto、vo 与 controller 同级，controller、mapper 仅使用 user 分组；entity 直接放实体类，dto、vo 使用 user 分组，service 只保留 impl 实现目录。统一返回和异常仍放 common 包，不再单独建立 Maven 子模块。

启动类仍是 com.petcommunity.PetCommunityApplication。后端 JAR 改为 backend/target/pet-community-0.1.0.jar，原有启停和重新构建脚本已同步。

在 IDEA 中打开 backend 文件夹，右键 pom.xml → Maven → 重新加载项目；也可以点击 Maven 面板的重新加载按钮。项目只有一个 Maven 模块，controller、service 等作为普通 Java 包显示。JDK 继续选择 17 或以上。

本次调整了代码位置、Java 包名、MyBatis 类型引用和构建路径；接口地址及数据库结构保持原设计。单模块构建、6 项单元测试、37 项真实接口检查和 12 项浏览器检查均通过。


## 包和注入写法

- controller/user：注册登录、资料、头像、会话和页面入口。
- mapper/user 与 resources/mapper/user：账号及头像的 MyBatis 接口和 XML。
- entity：直接放 UserEntity、MediaEntity，统一使用 @Data。
- dto/user、vo/user：请求参数与返回数据，统一使用 Lombok 数据类。
- service：业务接口；service/impl：对应实现，不再按业务继续分组。
- utils：头像文件保存与格式识别工具；其余保留 config、security、handler 等必要技术目录。

当前只有用户模块，管理员端开发时再添加 admin。Spring 管理的依赖显式用 @Autowired 字段注入，配置项用 @Value；普通请求和返回数据对象按需创建，不注册成单例 Bean。

实体和 DTO 使用 @Data 自动生成访问方法，VO 结合 @NoArgsConstructor、@AllArgsConstructor。密码与密码哈希从自动 toString 中排除。Maven 已配置 Lombok 依赖和注解处理器，打包时不携带 Lombok 本身。IDEA 修改后重新加载 Maven 项目；如 IDE 未识别 Lombok，请启用 Lombok 支持和注解处理。

单构造器省略 @Autowired 也是有效注入，这次依用户偏好统一改成显式字段注入。参考 [Spring 注入说明](https://docs.spring.io/spring-framework/reference/core/beans/annotation-config/autowired.html)、[Lombok @Data](https://projectlombok.org/features/Data) 和 [Lombok Maven 配置](https://projectlombok.org/setup/maven)。
