# 注册、登录与个人资料模块

本期已实现 Vue 3 页面、Spring Boot / MyBatis 接口及 MySQL 持久化。后端采用一个 Maven 模块，Java 源码统一放在 backend/src/main/java/com/petcommunity 下，资源和测试分别放在 src/main/resources 与 src/test/java。

## 1 已实现的功能

| 功能 | 行为 |
| --- | --- |
| 注册 | 账号、密码、昵称；账号忽略大小写归一化；注册成功自动登录 |
| 登录 | 账号密码校验，错误提示，显示/隐藏密码，回车提交 |
| 登录状态 | HttpOnly Session Cookie，刷新页面恢复，未登录访问资料页跳转登录 |
| 退出 | 服务端撤销当前 Session 并清除 Cookie，回到登录页 |
| 个人资料 | 查看和修改昵称、联系方式、所在地；账号保持只读 |
| 头像 | 本地预览、上传、更换、移除；真实文件存储及数据库绑定 |
| 保存反馈 | 字段校验、保存状态、成功/失败提示，版本冲突提示重新载入 |
| 页面适配 | 桌面与手机布局，320px 视口检查 |

本期未开发领养、社区内容、商城、管理端、密码修改及密码找回接口。精简后的完整接口文档和 25 张表设计是后续开发契约，不代表那些功能已经实现。

## 2 本期接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/v1/common/session | 初始化 Session 与 CSRF 令牌 |
| POST | /api/v1/user/auth/register | 注册并自动登录 |
| POST | /api/v1/user/auth/login | 登录 |
| GET | /api/v1/user/auth/me | 当前登录用户 |
| POST | /api/v1/user/auth/logout | 退出当前会话 |
| GET | /api/v1/user/profile | 查看本人资料 |
| PUT | /api/v1/user/profile | 完整更新本人资料，校验 version |
| POST | /api/v1/user/media | 上传头像；本期 businessType 仅 AVATAR |
| DELETE | /api/v1/user/media/{mediaId} | 删除本人未绑定头像 |
| GET | /api/v1/media/{mediaId}/content | 按权限读取头像，支持单段 Range |

请求、响应和错误码沿用[接口约定](../api/README.md)。成功为 HTTP 200，统一 code/message/data/requestId；读取图片为文件字节。后续类型 PET/POST/DIARY/HELP/PRODUCT 的上传暂未实现。

## 3 代码入口

- 后端控制器：backend/src/main/java/com/petcommunity/controller/user/UserAccountController.java。
- 账号业务：service/impl/UserAccountServiceImpl.java；认证和 CSRF：security/。
- 头像业务：service/impl/MediaServiceImpl.java，文件校验与保存：utils/AvatarStorage.java。
- MyBatis：mapper/user/UserMapper.java、mapper/user/MediaMapper.java 及 resources/mapper 对应 XML。
- 前端页面：frontend/src/views/user/auth/ 下的登录和注册，以及 views/user/profile/ProfileView.vue。
- 路由：frontend/src/router/index.js；登录状态：stores/auth.js；请求和 CSRF：utils/http.js。

## 4 数据与身份



密码使用 Spring Security PBKDF2 单向加盐哈希，支持接口允许的 8–64 个 Unicode 字符，保留密码中的空格。密码和哈希不会返回前端；注册请求不能指定角色。用户资料从 Session 确定归属，不接受客户端指定 ownerId 或修改账号状态。

Session 空闲有效期 8 小时，登录和注册轮换会话 ID 与 CSRF 令牌；写请求均验证 CSRF。浏览器不在 localStorage 中保存身份或密码。每次受保护请求查询账号状态与 auth_version，后续冻结或重置密码时可撤销旧会话。登录失败按账号和来源 IP 在 10 分钟内限制 10 次。

资料保存传 version；并发提交只有一个成功，失败返回 VERSION_CONFLICT。头像绑定检查上传者和用途；临时头像只对上传者可读，保存后作为当前头像可公开读取，移除后立即禁止读取。未绑定及已删除文件在 24 小时后由定时任务清理，任务每小时运行一次。

技术依据：[Spring Boot 3.5 运行要求](https://docs.spring.io/spring-boot/3.5/system-requirements.html)、[MyBatis Starter 兼容关系](https://mybatis.org/spring-boot-starter/mybatis-spring-boot-autoconfigure/)、[Spring Security 密码编码](https://docs.spring.io/spring-security/reference/features/authentication/password-storage.html)、[Vue 官方工程说明](https://vuejs.org/guide/quick-start.html)。

## 数据库精简

当前账号代码使用 sys_user、media_file 两张表；项目完整 25 张表现已建立。用户身份存 sys_user.role，只有 USER/ADMIN；前端响应 User.role 替代 roleIds 和 permissions。账号登录、会话、资料与头像功能保持，角色修改管理接口仍待开发。完整 25 张表已准备好，后续逐模块实现业务代码。
