# 数据字典 V1.1

完整设计 25 张，当前已全部建立。JSON 的条目校验、资源归属和状态流转见事务规则。

## sys_user · 用户账号与资料

普通用户和管理员共用账号表，通过 role 区分。注册固定为 USER；ADMIN 可操作管理端，不再提供自定义角色及逐项授权。冻结或角色变更递增 auth_version，现有会话失效。

| 字段 | 类型 | 可空 | 默认／生成 | 说明 |
| --- | --- | --- | --- | --- |
| id | BIGINT | 否 | AUTO_INCREMENT | 主键，自增，接口输出十进制字符串 |
| username | VARCHAR(24) CHARACTER SET ascii COLLATE ascii_bin | 否 | — | 小写账号，唯一 |
| password_hash | VARCHAR(255) CHARACTER SET ascii COLLATE ascii_bin | 否 | — | 带算法标识的单向密码哈希，绝不返回接口 |
| nickname | VARCHAR(24) | 否 | — | 昵称 |
| avatar_media_id | BIGINT | 是 | — | 头像媒体 ID，未设置为 NULL |
| phone | VARCHAR(32) | 否 | '' | 联系方式，可为空字符串 |
| location | VARCHAR(100) | 否 | '' | 所在地，可为空字符串 |
| status | VARCHAR(24) CHARACTER SET ascii COLLATE ascii_bin | 否 | 'ACTIVE' | 账号状态：ACTIVE/FROZEN |
| must_change_password | TINYINT | 否 | 0 | 管理员重置后是否必须修改密码 |
| auth_version | INT | 否 | 0 | 会话认证版本，冻结或改密时递增 |
| version | INT | 否 | 0 | 乐观锁，业务修改时由 Service 显式加 1 |
| created_at | DATETIME(3) | 否 | CURRENT_TIMESTAMP(3) | 创建时间，UTC |
| updated_at | DATETIME(3) | 否 | CURRENT_TIMESTAMP(3) | 更新时间，UTC，由 Service 显式维护 |
| role | VARCHAR(24) CHARACTER SET ascii COLLATE ascii_bin | 否 | 'USER' | 身份：USER 普通用户，ADMIN 管理员 |

主键：id。

- 唯一索引 `uk_user_username`：username
- 普通索引 `idx_user_status_created`：status, created_at, id
- 普通索引 `idx_user_role_status`：role, status, id

CHECK：

- `REGEXP_LIKE(`username`, '^[a-z0-9_]{3,24}$', 'c')`
- `CHAR_LENGTH(`nickname`) BETWEEN 1 AND 24`
- ``auth_version` >= 0`
- ``status` IN ('ACTIVE', 'FROZEN')`
- ``must_change_password` IN (0,1)`
- ``version` >= 0`
- ``role` IN ('USER','ADMIN')`

## media_file · 文件元信息与业务绑定

文件本体放文件系统或对象存储，MySQL 只保存元信息。DELETED 保留原关联便于禁止读取，生成列释放旧展示位置。

| 字段 | 类型 | 可空 | 默认／生成 | 说明 |
| --- | --- | --- | --- | --- |
| id | BIGINT | 否 | AUTO_INCREMENT | 主键，自增，接口输出十进制字符串 |
| owner_id | BIGINT | 否 | — | 上传者 ID |
| business_type | VARCHAR(24) CHARACTER SET ascii COLLATE ascii_bin | 否 | 'AVATAR' | 业务用途：AVATAR/PET/POST/DIARY/HELP/PRODUCT |
| business_id | BIGINT | 是 | — | 绑定业务 ID；未绑定为 NULL |
| sort_order | SMALLINT | 是 | — | 资源内展示顺序，头像 0，其余 1–9 |
| storage_key | VARCHAR(255) CHARACTER SET ascii COLLATE ascii_bin | 否 | — | 文件存储相对键，不返回磁盘路径 |
| original_name | VARCHAR(255) | 否 | — | 原文件名，仅供管理内部使用 |
| mime_type | VARCHAR(80) CHARACTER SET ascii COLLATE ascii_bin | 否 | — | 经文件特征校验后的 MIME |
| size_bytes | BIGINT | 否 | — | 文件字节数 |
| status | VARCHAR(24) CHARACTER SET ascii COLLATE ascii_bin | 否 | 'TEMP' | 生命周期：TEMP/BOUND/DELETED |
| active_business_id | BIGINT | 是 | CASE WHEN `status`='BOUND' THEN `business_id` ELSE NULL END | 仅有效绑定参与展示位置唯一约束 |
| cleanup_after | DATETIME(3) | 是 | — | 允许清理文件的 UTC 时间；有效绑定为空 |
| created_at | DATETIME(3) | 否 | CURRENT_TIMESTAMP(3) | 创建时间，UTC |
| updated_at | DATETIME(3) | 否 | CURRENT_TIMESTAMP(3) | 更新时间，UTC，由 Service 显式维护 |

主键：id。

- 唯一索引 `uk_media_storage_key`：storage_key
- 唯一索引 `uk_media_bound_sort`：business_type, active_business_id, sort_order
- 普通索引 `idx_media_owner`：owner_id, status, created_at
- 普通索引 `idx_media_cleanup`：status, cleanup_after, id

CHECK：

- ``business_type` IN ('AVATAR', 'PET', 'POST', 'DIARY', 'HELP', 'PRODUCT')`
- ``status` IN ('TEMP', 'BOUND', 'DELETED')`
- `(`status`='TEMP' AND `business_id` IS NULL AND `sort_order` IS NULL) OR (`status`='BOUND' AND `business_id` IS NOT NULL AND `sort_order` IS NOT NULL) OR `status`='DELETED'`
- ``sort_order` IS NULL OR (`business_type`='AVATAR' AND `sort_order`=0) OR (`business_type`<>'AVATAR' AND `sort_order` BETWEEN 1 AND 9)`
- `(`mime_type` IN ('image/jpeg','image/png','image/webp','image/gif') AND `size_bytes` BETWEEN 1 AND 5242880) OR (`business_type` NOT IN ('AVATAR','PRODUCT') AND `mime_type` IN ('video/mp4','video/webm') AND `size_bytes` BETWEEN 1 AND 20971520)`

## user_notice · 用户站内消息

群发主记录与收件消息共表。先建 is_broadcast=1 的主记录，再建立每个用户的消息并关联 broadcast_id；均在同事务提交。收件查询必须限定 recipient_id=当前用户 AND is_broadcast=0；Service 验证 broadcast_id 只指向主记录。允许收件人数为 0 的主记录。

| 字段 | 类型 | 可空 | 默认／生成 | 说明 |
| --- | --- | --- | --- | --- |
| id | BIGINT | 否 | AUTO_INCREMENT | 主键，自增，接口输出十进制字符串 |
| recipient_id | BIGINT | 是 | — | 收件人 |
| title | VARCHAR(100) | 否 | — | 标题 |
| content | TEXT | 否 | — | 接收人可见的摘要正文 |
| business_type | VARCHAR(24) CHARACTER SET ascii COLLATE ascii_bin | 否 | 'ADOPTION' | 业务类型：ADOPTION/COMMENT/ORDER/REFUND/REPORT/SYSTEM |
| business_id | BIGINT | 是 | — | 关联业务 ID，平台公告为 NULL |
| broadcast_id | BIGINT | 是 | — | 群发主记录 ID，普通业务消息为空 |
| is_read | TINYINT | 否 | 0 | 是否已读 |
| read_at | DATETIME(3) | 是 | — | 已读时间 |
| created_at | DATETIME(3) | 否 | CURRENT_TIMESTAMP(3) | 创建时间，UTC |
| is_broadcast | TINYINT | 否 | 0 | 1 群发主记录；0 实际收件消息 |
| target_type | VARCHAR(24) CHARACTER SET ascii COLLATE ascii_bin | 是 | — | 群发范围，仅群发主记录填写 |
| recipient_count | INT | 否 | 0 | 群发主记录的实际收件人数；普通消息为 0 |
| created_by | BIGINT | 是 | — | 群发管理员；普通业务消息为空 |

主键：id。

- 唯一索引 `uk_notice_broadcast_recipient`：broadcast_id, recipient_id
- 普通索引 `idx_notice_recipient_read`：recipient_id, is_read, created_at, id
- 普通索引 `idx_notice_recipient_created`：recipient_id, created_at, id
- 普通索引 `idx_notice_recipient_type`：recipient_id, business_type, created_at, id
- 普通索引 `idx_notice_broadcast`：is_broadcast, created_at, id

CHECK：

- ``business_type` IN ('ADOPTION', 'COMMENT', 'ORDER', 'REFUND', 'REPORT', 'SYSTEM')`
- `(`is_read`=0 AND `read_at` IS NULL) OR (`is_read`=1 AND `read_at` IS NOT NULL)`
- ``is_read` IN (0,1)`
- ``is_broadcast` IN (0,1)`
- ``recipient_count`>=0`
- `(`is_broadcast`=1 AND `recipient_id` IS NULL AND `broadcast_id` IS NULL AND `created_by` IS NOT NULL AND `target_type` IS NOT NULL AND `target_type` IN ('ALL','USERS') AND `business_type`='SYSTEM' AND `is_read`=0) OR (`is_broadcast`=0 AND `recipient_id` IS NOT NULL AND `target_type` IS NULL AND `created_by` IS NULL AND `recipient_count`=0)`

## api_idempotency · 幂等请求记录

先认证鉴权，再查重。成功记录与业务同事务提交；失败事务回滚记录。应用密钥不在数据库保存，防止临时密码幂等响应明文落库。

| 字段 | 类型 | 可空 | 默认／生成 | 说明 |
| --- | --- | --- | --- | --- |
| id | BIGINT | 否 | AUTO_INCREMENT | 主键，自增，接口输出十进制字符串 |
| user_id | BIGINT | 否 | — | 用户 ID |
| http_method | VARCHAR(8) CHARACTER SET ascii COLLATE ascii_bin | 否 | — | HTTP 方法 |
| request_path | VARCHAR(255) CHARACTER SET ascii COLLATE ascii_bin | 否 | — | 包含实际 ID 的规范请求路径 |
| idempotency_key | CHAR(36) CHARACTER SET ascii COLLATE ascii_bin | 否 | — | 客户端 UUID |
| request_hash | BINARY(32) | 否 | — | 规范化请求 SHA-256 摘要，包含请求体和有业务含义的查询参数 |
| state | VARCHAR(24) CHARACTER SET ascii COLLATE ascii_bin | 否 | 'PROCESSING' | 执行状态：PROCESSING/SUCCEEDED |
| http_status | INT | 是 | — | 成功响应 HTTP 状态 |
| response_ciphertext | MEDIUMBLOB | 是 | — | 成功响应加密字节，含 nonce 与认证标签；PROCESSING 为空 |
| encryption_key_id | VARCHAR(80) CHARACTER SET ascii COLLATE ascii_bin | 是 | — | 应用侧加密密钥版本标识 |
| expires_at | DATETIME(3) | 否 | — | 24 小时幂等缓存到期时间 |
| created_at | DATETIME(3) | 否 | CURRENT_TIMESTAMP(3) | 创建时间，UTC |
| updated_at | DATETIME(3) | 否 | CURRENT_TIMESTAMP(3) | 更新时间，UTC，由 Service 显式维护 |

主键：id。

- 唯一索引 `uk_idem_scope`：user_id, http_method, request_path, idempotency_key
- 普通索引 `idx_idem_expiry`：expires_at, id

CHECK：

- ``state` IN ('PROCESSING', 'SUCCEEDED')`
- `(`state`='PROCESSING' AND `http_status` IS NULL AND `response_ciphertext` IS NULL AND `encryption_key_id` IS NULL) OR (`state`='SUCCEEDED' AND `http_status` IS NOT NULL AND `http_status`=200 AND `response_ciphertext` IS NOT NULL AND `encryption_key_id` IS NOT NULL)`
