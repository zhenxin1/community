## 演示准备

确认MySQL、应用和本地资源可用，准备发布者、两名申请者、消费者及ADMIN账号。使用教学地址和联系方式，不展示数据库密码、会话令牌或随机账号密码文件。准备一只用于成功交接、另一只用于失败恢复的宠物，以及库存充足和最后一件的商品。演示内容按下表组织，实际视频链接已在提交材料索引登记。

| 时间 | 操作与讲解 | 重点 |
|---|---|---|
| 0:00—1:00 | 介绍用户、领养与购买两条流程、系统结构 | 解释业务目标和关键约束 |
| 1:00—2:00 | 发布宠物，按地区品种查找，展示游客和登录联系权限 | FR-06—08，信息与隐私 |
| 2:00—4:00 | 两名用户申请，发布者选定；单方确认等待、双方完成；展示失败恢复记录 | FR-09—12，唯一轮次与结果 |
| 4:00—5:30 | 分类选购、勾选、地址和优惠报价，建单 | FR-13、15—18，金额快照 |
| 5:30—7:00 | 模拟失败后成功付款；ADMIN发货，消费者确认收货 | FR-19—21，库存及履约 |
| 7:00—8:00 | ADMIN查询、原因冻结、旧会话拒绝、解冻重登和通知 | FR-02、04—05 |
| 8:00—9:00 | 抽两条FR核对ADR、故事、代码和实际测试 | 可追溯性及并发风险处理 |
| 9:00—10:00 | 说明实验A观察、限制、AI使用与真实分工 | 不把单样本当因果证明 |
