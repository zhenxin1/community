## API101 管理员登录

`POST /api/v1/admin/auth/login`

账号必须 ACTIVE 且拥有至少一个管理角色；普通账号返回 FORBIDDEN。账号密码错误提示与用户登录一致。成功轮换会话 ID 与 CSRF 令牌。

需求：5.1。成功 HTTP 200；统一响应包裹。

实现状态：待开发。需求：5.1。

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| X-CSRF-Token | header | string | 是 | 由 common/session 或登录结果获得，随登录更新 {} |

请求体：`application/json`

| 字段 | 类型 | 必填 | 说明与约束 |
| --- | --- | --- | --- |
| username | string | 是 | 账号 {"minLength": 3, "maxLength": 24} |
| password | string | 是 | 密码 {"minLength": 1, "maxLength": 64, "format": "password"} |

```json
{
  "username": "pet_lover",
  "password": "ExamplePass123!"
}
```

响应 `200`：操作成功

类型：`ResultAuthResult`，详见数据模型。

```json
{
  "code": "OK",
  "message": "成功",
  "data": {
    "user": {
      "id": "1001",
      "username": "admin_example",
      "nickname": "平台管理员",
      "avatarId": "",
      "phone": "13800138000",
      "location": "武汉",
      "status": "ACTIVE",
      "mustChangePassword": false,
      "version": 1,
      "createdAt": "2026-11-11T10:00:00+08:00",
      "role": "ADMIN"
    },
    "csrfToken": "csrf_after_login",
    "expiresInSeconds": 28800
  },
  "requestId": "req_20261111_001"
}
```

响应 `400`：VALIDATION_ERROR: 字段缺失、类型错误、未知字段、枚举或跨字段约束不满足

类型：`Error`，详见数据模型。

响应 `404`：RESOURCE_NOT_FOUND: 资源不存在、已删除或不属于当前用户

类型：`Error`，详见数据模型。

响应 `500`：INTERNAL_ERROR: 未预期的服务端异常，写事务回滚

类型：`Error`，详见数据模型。

响应 `403`：CSRF_INVALID: 写请求令牌缺失或失效；ACCOUNT_FROZEN: 账号被冻结；FORBIDDEN: 缺少管理员身份或不允许该操作

类型：`Error`，详见数据模型。

响应 `409`：STATE_CONFLICT: 当前状态不支持此操作

类型：`Error`，详见数据模型。

响应 `429`：TOO_MANY_REQUESTS: 登录失败或提交频率触发限流

类型：`Error`，详见数据模型。

响应 `401`：INVALID_CREDENTIALS: 账号或密码错误

类型：`Error`，详见数据模型。

## API113 核验身份后重置密码

`POST /api/v1/admin/users/{userId}/password-reset`

管理员在系统外人工核验身份，说明核验及重置原因。生成随机临时密码并仅在本次操作结果返回，必须先改密；撤销目标全部会话。普通管理者不得重置管理员或权限超出自身的管理账号。临时密码不进日志，幂等响应加密保存 24 小时。

需求：1.2,5.2。成功 HTTP 200；统一响应包裹。
管理权限：ADMIN。

实现状态：待开发。需求：1.2, 5.2。

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| userId | path | string | 是 | 资源 ID，详见路径名称 {"pattern": "^[1-9][0-9]{0,18}$"} |
| X-CSRF-Token | header | string | 是 | 由 common/session 或登录结果获得，随登录更新 {} |
| Idempotency-Key | header | string | 是 | UUID；同一业务动作重试必须保持相同；有效期 24 小时 {} |

请求体：`application/json`

| 字段 | 类型 | 必填 | 说明与约束 |
| --- | --- | --- | --- |
| reason | string | 是 | 操作原因 {"minLength": 1, "maxLength": 500} |
| version | integer | 是 | 乐观锁版本，更新时传读取到的当前版本 {"minimum": 0} |

```json

  "reason": "示例说明",
  "version": 1
```

响应 `200`：操作成功

响应 `400`：VALIDATION_ERROR: 字段缺失、类型错误、未知字段、枚举或跨字段约束不满足；MISSING_IDEMPOTENCY_KEY: 需要防重复的请求未携带幂等键

类型：`Error`，详见数据模型。

响应 `409`：STATE_CONFLICT: 当前状态不支持此操作；VERSION_CONFLICT: 传入 version 已过期；IDEMPOTENCY_CONFLICT: 同一幂等键对应不同内容或同键请求正在处理
