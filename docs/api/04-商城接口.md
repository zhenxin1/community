## API078 商品分类列表

`GET /api/v1/shop/categories`

按通用约定执行；本人资源仅对本人开放。

需求：4.1。成功 HTTP 200；统一响应包裹。

实现状态：待开发。需求：4.1。

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| page | query | integer | 否 | 页码，从 1 开始 {"minimum": 1, "default": 1} |
| pageSize | query | integer | 否 | 每页条数，最大 100 {"minimum": 1, "maximum": 100, "default": 20} |

响应 `200`：操作成功

类型：`ResultCategoryPage`，详见数据模型。

```json
{
  "code": "OK",
  "message": "成功",
  "data": {
    "records": [],
    "total": 0,
    "page": 1,
    "pageSize": 20
  },
  "requestId": "req_20261111_001"
}
```

响应 `400`：VALIDATION_ERROR: 字段缺失、类型错误、未知字段、枚举或跨字段约束不满足

类型：`Error`，详见数据模型。

响应 `404`：RESOURCE_NOT_FOUND: 资源不存在、已删除或不属于当前用户

类型：`Error`，详见数据模型。

响应 `500`：INTERNAL_ERROR: 未预期的服务端异常，写事务回滚

类型：`Error`，详见数据模型。

## API079 公开商品列表

`GET /api/v1/shop/products`

仅 ON_SHELF 且分类启用；默认 LATEST，所有排序最后追加 ID 降序。

需求：4.1。成功 HTTP 200；统一响应包裹。

实现状态：待开发。需求：4.1。

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| page | query | integer | 否 | 页码，从 1 开始 {"minimum": 1, "default": 1} |
| pageSize | query | integer | 否 | 每页条数，最大 100 {"minimum": 1, "maximum": 100, "default": 20} |
| keyword | query | string | 否 | 需求 description 包含关键词，空值表示全部 {} |
| categoryId | query | string | 否 | 资源 ID，十进制字符串 {"pattern": "^[1-9][0-9]{0,18}$"} |
| minPriceCents | query | integer | 否 | 最低单价，分 {"minimum": 0, "maximum": 9999999999} |
| maxPriceCents | query | integer | 否 | 最高单价，分 {"minimum": 0, "maximum": 9999999999} |
| sort | query | string | 否 | 排序 {"enum": ["LATEST", "PRICE_ASC", "PRICE_DESC"]} |

响应 `200`：操作成功

类型：`ResultProductPage`，详见数据模型。

```json
{
  "code": "OK",
  "message": "成功",
  "data": {
    "records": [],
    "total": 0,
    "page": 1,
    "pageSize": 20
  },
  "requestId": "req_20261111_001"
}
```

响应 `400`：VALIDATION_ERROR: 字段缺失、类型错误、未知字段、枚举或跨字段约束不满足

类型：`Error`，详见数据模型。

响应 `404`：RESOURCE_NOT_FOUND: 资源不存在、已删除或不属于当前用户

类型：`Error`，详见数据模型。

响应 `500`：INTERNAL_ERROR: 未预期的服务端异常，写事务回滚

类型：`Error`，详见数据模型。
