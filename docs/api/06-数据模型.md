# 数据模型

接口请求和响应以 [openapi.json](openapi.json) 为准。所有字段类型、必填项与枚举如下；ID 使用十进制字符串，金额单位为分。数据库实体不直接当接口返回。

## ActionResult

通用操作结果

| 字段 | 类型 | 必填 | 说明与约束 |
| --- | --- | --- | --- |
| success | boolean | 是 | 是否完成  |

## FieldError

字段错误

| 字段 | 类型 | 必填 | 说明与约束 |
| --- | --- | --- | --- |
| field | string | 是 | 字段路径  |
| message | string | 是 | 错误信息  |

## Error

错误返回体

| 字段 | 类型 | 必填 | 说明与约束 |
| --- | --- | --- | --- |
| code | string | 是 | 稳定业务码  |
| message | string | 是 | 面向用户的提示  |
| requestId | string | 是 | 请求追踪编号  |
| fieldErrors | array<FieldError> | 是 | 校验错误，其他错误返回空数组  |

## Session

预初始化会话和 CSRF 令牌

| 字段 | 类型 | 必填 | 说明与约束 |
| --- | --- | --- | --- |
| authenticated | boolean | 是 | 是否已登录  |
| csrfToken | string | 是 | 后续写请求的 X-CSRF-Token  |

## User

当前账号资料，只在本人及授权管理端返回完整联系方式

| 字段 | 类型 | 必填 | 说明与约束 |
| --- | --- | --- | --- |
| id | string | 是 | 资源 ID，十进制字符串 {"pattern": "^[1-9][0-9]{0,18}$"} |
| username | string | 是 | 账号  |
| nickname | string | 是 | 昵称  |
| avatarId | string | 是 | 头像媒体 ID，未设置时为空字符串  |
| phone | string | 是 | 联系电话，可为空  |
| location | string | 是 | 所在地  |
| status | string | 是 | 账号状态 {"enum": ["ACTIVE", "FROZEN"]} |
| mustChangePassword | boolean | 是 | 管理员重置后必须先修改密码  |
| version | integer | 是 | 乐观锁版本，更新时传读取到的当前版本 {"minimum": 0} |
| createdAt | string | 是 | 时间，RFC3339，使用北京时间偏移 {"format": "date-time"} |
| role | string | 是 | 固定身份，注册只能为 USER {"enum": ["USER", "ADMIN"]} |

## AuthResult

登录或注册成功，响应同时设置会话 Cookie

| 字段 | 类型 | 必填 | 说明与约束 |
| --- | --- | --- | --- |
| user | User | 是 |   |
| csrfToken | string | 是 | 登录后重新生成的 CSRF 令牌  |
| expiresInSeconds | integer | 是 | 会话空闲有效期秒数  |
