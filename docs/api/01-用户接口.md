## API002 上传用户媒体

`POST /api/v1/user/media`

校验扩展名、MIME 与文件特征。图片≤5MB，视频≤20MB，头像仅图片。返回 mediaId；上传者才可把临时媒体绑定至本人资源。同一媒体仅绑定一个业务对象。 用户接口禁止 PRODUCT；用途须匹配后续资源。返回模型中的 id 即媒体 ID。

需求：COMMON。成功 HTTP 200；统一响应包裹。

实现状态：已实现。需求：COMMON。

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| X-CSRF-Token | header | string | 是 | 由 common/session 或登录结果获得，随登录更新 {} |

请求体：`multipart/form-data`

| 字段 | 类型 | 必填 | 说明与约束 |
| --- | --- | --- | --- |
| businessType | string | 是 | 用途 {"enum": ["AVATAR", "PET", "POST", "DIARY", "HELP", "PRODUCT"]} |
| file | string | 是 | JPEG、PNG、WebP、GIF 图片不超过 5MB；MP4、WebM 视频不超过 20MB；头像仅图片 {"format": "binary"} |

响应 `200`：操作成功

类型：`ResultMedia`，详见数据模型。

```json
{
  "code": "OK",
  "message": "成功",
  "data": {
    "id": "1001",
    "businessType": "AVATAR",
    "mimeType": "image/jpeg",
    "sizeBytes": 102400,
    "contentPath": "/api/v1/media/1001/content",
    "createdAt": "2026-11-11T10:00:00+08:00"
  },
  "requestId": "req_20261111_001"
}
```

响应 `400`：VALIDATION_ERROR: 字段缺失、类型错误、未知字段、枚举或跨字段约束不满足

类型：`Error`，详见数据模型。

响应 `404`：RESOURCE_NOT_FOUND: 资源不存在、已删除或不属于当前用户

类型：`Error`，详见数据模型。

响应 `500`：INTERNAL_ERROR: 未预期的服务端异常，写事务回滚

类型：`Error`，详见数据模型。

响应 `401`：UNAUTHENTICATED: 未登录、会话失效或已退出

类型：`Error`，详见数据模型。

响应 `403`：ACCOUNT_FROZEN: 账号被冻结；PASSWORD_CHANGE_REQUIRED: 管理员重置后尚未修改临时密码；CSRF_INVALID: 写请求令牌缺失或失效

类型：`Error`，详见数据模型。

响应 `409`：STATE_CONFLICT: 当前状态不支持此操作

类型：`Error`，详见数据模型。

响应 `429`：TOO_MANY_REQUESTS: 登录失败或提交频率触发限流

类型：`Error`，详见数据模型。

响应 `413`：FILE_TOO_LARGE: 单文件或请求体超过大小限制

类型：`Error`，详见数据模型。

响应 `415`：UNSUPPORTED_MEDIA_TYPE: 请求类型或上传文件实际格式不支持

类型：`Error`，详见数据模型。

## API005 注册账号

`POST /api/v1/user/auth/register`

账号小写归一后唯一；昵称去首尾空白。密码 8–64 字符，保存加盐哈希。注册成功自动登录并轮换会话 ID 与 CSRF 令牌。

需求：1.1。成功 HTTP 200；统一响应包裹。

实现状态：已实现。需求：1.1。

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| X-CSRF-Token | header | string | 是 | 由 common/session 或登录结果获得，随登录更新 {} |

请求体：`application/json`

| 字段 | 类型 | 必填 | 说明与约束 |
| --- | --- | --- | --- |
| username | string | 是 | 账号，后端转小写后判重 {"pattern": "^[A-Za-z0-9_]{3,24}$"} |
| password | string | 是 | 密码，8–64 字符 {"minLength": 8, "maxLength": 64, "format": "password"} |
| nickname | string | 是 | 昵称 {"minLength": 1, "maxLength": 24} |

```json
{
  "username": "pet_lover",
  "password": "ExamplePass123!",
  "nickname": "小爪同学"
}
```

响应 `200`：操作成功

类型：`ResultAuthResult`，详见数据模型。

响应 `400`：VALIDATION_ERROR: 字段缺失、类型错误、未知字段、枚举或跨字段约束不满足
