## API057 获取启用中的社区分类

`GET /api/v1/community/categories`

按 sort 升序、ID 升序。

需求：3.5。成功 HTTP 200；统一响应包裹。

实现状态：待开发。需求：3.5。

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| page | query | integer | 否 | 页码，从 1 开始 {"minimum": 1, "default": 1} |
| pageSize | query | integer | 否 | 每页条数，最大 100 {"minimum": 1, "maximum": 100, "default": 20} |

响应 `200`：操作成功

类型：`ResultCategoryPage`，详见数据模型。

```json

  "code": "OK",
  "message": "成功",
  "data": {
    "records": [],
    "total": 0,

  "requestId": "req_20261111_001"
}
```

响应 `400`：VALIDATION_ERROR: 字段缺失、类型错误、未知字段、枚举或跨字段约束不满足

类型：`Error`，详见数据模型。

## API058 公开社区内容列表

`GET /api/v1/community/posts`

仅 PUBLIC+PUBLISHED。可选会话用于返回 liked/favorited；匿名均 false。默认创建时间降序、ID 降序。

需求：3.5。成功 HTTP 200；统一响应包裹。

实现状态：待开发。需求：3.1, 3.2, 3.3, 3.5。

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| page | query | integer | 否 | 页码，从 1 开始 {"minimum": 1, "default": 1} |
| pageSize | query | integer | 否 | 每页条数，最大 100 {"minimum": 1, "maximum": 100, "default": 20} |
| keyword | query | string | 否 | 需求 description 包含关键词，空值表示全部 {} |
| kind | query | string | 否 | 内容类型 {"enum": ["POST", "DIARY", "HELP"]} |
| categoryId | query | string | 否 | 分类 ID {"pattern": "^[1-9][0-9]{0,18}$"} |
| tag | query | string | 否 | 单标签精确匹配 {} |

响应 `200`：操作成功

类型：`ResultPostPage`，详见数据模型。

```json
{
  "code": "OK",
  "message": "成功",
  "data": {
    "records": [],
    "total": 0,

  },
  "requestId": "req_20261111_001"
}
```

响应 `400`：VALIDATION_ERROR: 字段缺失、类型错误、未知字段、枚举或跨字段约束不满足

类型：`Error`，详见数据模型。
