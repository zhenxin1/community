# 业务验收清单

本清单定义最终验收场景和预期结果。执行结论以对应记录为准，清单本身不预填通过状态；故事状态由Sprint文件统一维护。

| 编号 | 场景与操作 | 预期结果 | 对应需求 |
|---|---|---|---|
| AT-01 | 注册、登录、退出和非法角色字段提交 | 创建唯一USER；正确凭据登录；退出后当前会话失效；角色注入拒绝 | FR-01—02 |
| AT-02 | 修改资料、重复提交旧版本、修改密码 | 资料按版本更新；旧版本冲突；改密撤销旧会话 | FR-02—03 |
| AT-03 | 管理员查询、冻结、解冻并查看通知 | 状态和说明一致；冻结撤销会话；解冻后重新登录；通知只供本人读取 | FR-04—05 |
| AT-04 | 发布宠物，按名称、类别、地区、品种筛选 | 保存合法资料和图片；组合筛选只返回匹配项 | FR-06—07 |
| AT-05 | 游客、普通用户和交接当事人查看联系方式 | 游客不获得联系字段；登录且待领养时可联系；交接期间按当事关系收紧 | FR-08 |
| AT-06 | 两用户申请同一宠物，发布者选定一份 | 禁止自申请和重复有效申请；当前选定唯一 | FR-09—10 |
| AT-07 | 单方、双方、重复及无关用户提交成功确认 | 单方仍待交接；双方形成唯一成功结果；越权请求拒绝 | FR-11 |
| AT-08 | 任一方确认失败，再选定新轮次并重放旧请求 | 保留取消历史、恢复待领养；旧轮次不影响新交接 | FR-12 |
| AT-09 | 分类搜索、商品维护及购物车部分勾选 | 公开目录只显示可售商品；管理操作鉴权；结算集合只含选中行 | FR-13—15 |
| AT-10 | 管理地址、检查满减八折、报价后修改地址并提交 | 地址属于本人；服务端金额正确；资料变化要求重新确认报价 | FR-16—18 |
| AT-11 | 模拟付款失败、成功、重复及竞争最后一件库存 | 失败不扣库存；成功全单扣减一次；并发仅一单成功 | FR-19 |
| AT-12 | 查看订单、取消待付款、后台发货和本人收货 | 快照保持；取消与付款互斥；仅已付款可发货；本人确认完成 | FR-20—21 |
| AT-13 | 核对隐私、事务、金额与可运行证据 | 各项满足PRD的NFR-01—05量化标准 | NFR-01—05 |

## 验收记录字段

每次执行记录代码版本、环境、执行者、实际步骤、结果、问题和验证材料。通过条件为对应断言满足、无未解决的阻断问题、需求与实现一致，并取得人工接受结论。用例失败及后续修补分别保留。
