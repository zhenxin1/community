# 收货信息

购买者需要在结算前新增、编辑并选择收货姓名、电话和地址。

- 已勾选有效商品、报价成功且没有地址时，进入结算并保存填写的姓名、电话和地址；新地址返回不透明 ID 与版本，能够被选择。页面依次展示收货信息、所选商品与金额、支付区域。没有可结算商品时引导返回购物车；尚未接通的支付区域不能提供虚假付款动作。
- 地址 A 已保存并选中且存在 B 时，内联编辑 A 并保存，或改选 B 后重新读取页面：A 的修改和递增版本可读取，选中 B 时显示其完整姓名、电话和地址；其他地址不变。保存后焦点回到原收货信息区域；不新增独立用户中心或地址地图。
- 新增或编辑时任何必填字段为空或仅为空白，包括直接向接口提交时，页面显示关联字段的错误并聚焦首个无效项，服务返回 400 且不写入或递增版本，保留其他已填内容。只做非空校验，不强制手机号正则、短信验证或真实地址核验。
- 填写有效演示信息后遇到服务不可用或运行身份变化，不能提示保存成功；旧运行的写入返回 409 RUN_CHANGED，不能自动重放，用户在新运行重新开始。标签常显、可用键盘操作，错误和禁用不能只靠颜色，200% 缩放不遮挡字段或金额；日志不包含收货信息。
