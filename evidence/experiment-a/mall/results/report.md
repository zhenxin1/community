# 实验 A 简要记录

按用户要求，本次为课程作业的探索性比较，未建立严格隔离环境。X取得规划材料并实现购物车；Y取得业务需求和固定夹具并实现收货信息。两者任务不同，不能据此判断哪种方法更优或声称因果关系。

X 和 Y 分别在无聊天继承的代理会话及各自任务目录中执行，但文件系统和工具没有严格阻断其他材料；两组执行时间有重叠。初始输入清单、哈希、会话标识及时间见 `../freeze-manifest.json`；部分后续引导消息未逐字归档。模型精确版本、人工有效时间及污染情况未独立核实。

首轮提示原文保存在本目录 `X-prompt.txt`、`Y-prompt.txt`；它们是发给代理的消息，不证明系统自动上下文及实际读取范围。统一评审表的编码前摘要未留证，当前不能证明标准事前冻结。原始终端日志未保存，两组测试数字来自实施者报告。

X报告类型检查和 `npm test` 通过（构建及2项测试）；Y报告 `npm test` 通过（构建及2项测试）。两组独立结果保留在本目录的 `X/`、`Y/`；它们分别验证各自任务，不是等量难度或完整产品验收。Y的固定购物车和报价不代表真实集成。

之后组织者将购物车与收货信息适配到主工程的共享接口，并补充真实购物车报价。主工程的后续测试和浏览器检查属于集成验证，不计作两组原始比较结果。未取得人工耗时和统一独立评分，相关指标不计算。
